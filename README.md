# Minecraft Mods for 1.12.2 Forge

Это репозиторий содержит два мода для Minecraft 1.12.2 с Forge.

## Моды

### 1. LAN World Plug-n-Play
**lanworld** - Мод для легкого открытия вашего мира для друзей в сети без использования Realms.

**Возможности:**
- Быстрое открытие мира для игроков в сети
- Простое управление доступом
- Поддержка до 8 игроков в одной сети
- Автоматическое обнаружение мира

### 2. Weapons Mod
**weaponsmod** - Мод, добавляющий продвинутое оружие в игру.

**Доступное оружие:**

#### Снайперские винтовки:
- **SVD** - Классическая советская снайперская винтовка (урон: 8.0)
- **AWP** - Легендарная винтовка из CS:GO (урон: 10.0)
- **Barrett M82** - Тяжелая снайперская винтовка (урон: 12.0)

#### Кастомные ножи:
- **Butterfly Knife** (Нож-бабочка) - урон 6.0, скорость 0.8
- **Karambit** (Керамбит) - урон 5.0, скорость 1.0
- **M9 Bayonet** (Штык М9) - урон 5.5, скорость 0.9

## Установка

1. Установите Minecraft Forge 1.12.2 (версия 14.23.5.2860 или выше)
2. Скачайте JAR файлы модов из папки `build/libs/`
3. Поместите их в папку `%appdata%/.minecraft/mods/` (Windows) или `~/.minecraft/mods/` (Linux/Mac)
4. Запустите Minecraft с профилем Forge

## Компиляция

```bash
# Установите JAVA_HOME и запустите
./gradlew setupDecompWorkspace
./gradlew eclipse
./gradlew build
```
